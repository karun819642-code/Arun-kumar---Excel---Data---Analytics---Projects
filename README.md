## 📊 Project Description

This project is an interactive **Hospital Emergency Room Dashboard** created using **Microsoft Excel**.

The dashboard provides a monthly analysis of hospital emergency room data and helps understand patient volume, waiting time, satisfaction, attendance status, gender distribution, age groups, and department referrals.

### 📌 Key Insights

- 👥 Total Number of Patients
- ⏱️ Average Wait Time
- ⭐ Patient Satisfaction
- 📅 Monthly Patient Analysis
- 🚑 Patient Attendance Status – On-time vs Delay
- 👨‍⚕️ Gender-wise Analysis
- 🏥 Admission Status – Admitted vs Not Admitted
- 👶 Age Group-wise Patient Analysis
- 🩺 Department Referral Analysis

### 🛠️ Tools Used

- Microsoft Excel
- Excel Charts
- Pivot Tables
- Data Analysis
- Dashboard & Data Visualization

### 🎯 Project Objective

The main objective of this project is to analyze emergency room patient data and create an interactive dashboard that makes hospital performance and patient trends easy to understand.
